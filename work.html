Question 1: Super Shop Bill

  1. A customer buys products from a super shop.
  2. Write a JavaScript program to calculate the final bill.
  3. If the shopping amount is 5000 or more, give 10% discount.
  4. If the shopping amount is 3000 or more, give 5% discount.
  5. Otherwise, there is no discount.
  6. After discount, add 5% VAT.
  7. Calculate and display the final bill.

Question 2: Ride Fare Calculator

  1. A person travels by taxi.
  2. Write a JavaScript program to calculate the total fare based on distance.
  3. First 2 km → 50 Tk per km.
  4. Next 3 km → 40 Tk per km.
  5. More than 5 km → 30 Tk per extra km.
  6. Take the distance and calculate the total fare.

Question 3: Student Grade Calculator

  1. A student has marks in Bangla, English and Math.
  2. Write a JavaScript program to calculate the student's total marks, average marks and grade.
  3. 80 or above → A+
  4. 70 or above → A
  5. 60 or above → B
  6. 50 or above → C
  7. 40 or above → D
  8. Below 40 → F
  9. If any subject mark is below 33, the student will be Fail.

Question 4: Electricity Bill

  1. Write a JavaScript program to calculate an electricity bill based on the number of units used.
  2. First 100 units → 5 Tk per unit.
  3. Next 100 units → 7 Tk per unit.
  4. More than 200 units → 10 Tk per extra unit.
  5. Take the number of units and calculate the total electricity bill.
